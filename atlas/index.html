01 / CONTROL

Measure the baseline

Ask “Who are you?” using Inkling-Small’s chat template with reasoning disabled. Record the greedy reply and the median norm of the layer’s residual vectors across prompt tokens, excluding the first token.

02 / INTERVENTION

Change one direction

Add or subtract a normalized down-projection column after the chosen decoder block. Scale the push by the baseline residual norm and the recorded strength.

03 / COMPARISON

Read the reply

Compare each steered reply with the unsteered baseline. Optional labels and scores live alongside the original text. Each observation describes one prompt and intervention.

How do expert neurons work here?

Layer and neuron identify a dense coordinate. Mixture-of-experts coordinates also include expert type and index. The same residual intervention uses that expert’s down-projection column directly. For routed experts, this deliberately bypasses routing and tests the direction regardless of which experts the token selected.

What does a persona label mean?

A persona label describes a reply in which the model took on a different identity. Labels are interpretations of individual replies. Other prompts, checkpoints and intervention settings can yield different replies.

Where do the data come from?

The experiment runner exports the checkpoint, prompt, baseline and intervention replies as JSON. This viewer loads run files in the current browser tab. Model architecture comes from the published Inkling-Small configuration.
